# PERF-2a インク再利用と特徴量フィルター範囲縮小

確認日：2026-09-21。変更前はメモリ削減済みの `0ba9fcb0ead84550a852bd654ebfe0ff1ac38161`。ユーザーが承認した逐次最適化②③だけを実装した。対象区間による探索の走査削減、SIMD、並列化は今回の変更に含めない。

## 実装と所有権

`PageComparer.Compare` が1回の比較だけに使う `ComparisonInk` を所有する。位置ずれのグループ化で使用した A/B のインクに対し、参照カウント付き Mat ヘッダーを取得する。画素をコピーせず、分類までインクだけを引き継ぐ。平滑化・コントラストの大きな Mat は、従来どおり `TolerantDifference.Calculate` の終了時に破棄する。

再利用は同じ入力 Mat の組・DPI・`InkOptions` に限定する。別画像・逆向きの組・条件不一致では分類に必要な ROI から再計算する。完全一致、候補なし、位置ずれ探索なしではインクを引き継がない。分類無効の内部経路と公開 `TolerantDifference.Calculate` は引き継ぎ用の所有者を作らない。公開API・`RawDifference` の所有権は変えていない。

分類では生成済みインクの対象領域と、必要な場合だけ上下左右1pxの膨張用余白を読む。Lab変換と局所背景の計算を繰り返さない。インクは元のA/B（全体補正後の比較なら補正後B）に対応し、グループの吸収量ではずらさない。ページ比較終了時には `using` で解放し、例外経路も同じ所有者が後始末する。取得の途中で失敗した場合は、取得済みの片側を解放し、不完全な組を公開しない。

特徴量生成は128行の帯処理を維持する。Lab・インク用には局所背景半径の余白を残し、3×3平滑化・5×5最大/最小値の処理範囲を帯の上下2pxまでに限定した。保存する中央部分の計算には必要な近傍が残るため、偽の画像端を作らない。

比較式、float32精度、解像度、しきい値、設定、位置ずれの探索順・同点処理、出力形式、参照実装と期待値は変更していない。新規依存・強制GC・スレッド設定変更も追加していない。

## 処理時間と最大メモリ

Apple M4 Max（16コア・RAM 128GiB）、macOS 26.5.1、.NET Runtime 10.0.12。伊勢市の公開工程表と変更工程表の1組を通常設定・`--save-all-pages` で比較した。300dpiはA3横4960×3508px。4ページ入力は同じページを4回複製したPDF。
