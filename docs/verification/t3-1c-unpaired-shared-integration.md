## 証拠・出力・予算

`PageFlowPlan`は単一原因・独立成分の既存成功を優先する。追加の曖昧候補再検証は、文書・凍結済み候補／レイアウト・実効設定を確認する内部入口に限定した。全対応ページ2枚以上、末尾片側1枚、明示選択なし、300dpi／normal相当、全体補正無効、数値対応・除外・領域なしを必要とする。全境界を実際の跨ぎが同方向に連結し、跨ぐ全行が完全な末尾／先頭帯を埋める既存適格変位を使う。最大値を単純に選ばず、候補ID2を保持した。非送り証明と新しい共有経路を混在させない。

元帯の全画素一致、置換比較、各ページの局所支持・改善率、C/D、片側ページの全非白残余の確認は既存関数を使う。共有成分は実構造を原因・移動・送り端点へ一度ずつ所属させ、原因の寄与・累積移動量／送り高・ページ収支を検査する。末尾の送り先は本文全体を覆う一つの補助帯であり、構造IDや原因件数を作らない。両方の網羅性falseと `only_in_a/b` を保持する。

共有成分と末尾リンクの `auxiliary_bands` は元画像Oの端点形式で、側・ページ・矩形・mm・保存済み帯画像と空の構造参照を持つ。HTMLは未比較の説明と元帯画像・元ページへのリンクを表示する。既存の全対応ページでは任意プロパティを省略し、旧JSON／HTMLを維持する。

予約は[仕様の計上式](../planning/t3-1c-unpaired-shared-diagnosis.md#承認範囲の出力予約契約2026-09-27)を同じ64MiBの残りへ適用する。A/B両方向で候補再検証と成分集約の上限ちょうどを許可し、1B不足は全追加証拠／全グループを取り消す。集約だけの不足は採用済みC/Dと未集約件数を維持する。再試行で予約を累積消費しない。別文書・候補／行配置・本文・設定の差し替え、実構造の欠落／重複／除外、送りの欠落／端点破損、片側被覆取消を拒否し、内容1件の追加は集約後にも1件加算する。
