# v0.1.2 サンプル画面・性能改善の配布準備

確認日：2026-09-21。v0.1.1からPERF-1〜PERF-2jまでの性能改善を含む。比較式・設定の既定値・依存バージョン・ネイティブDLLは維持し、READMEに自作データによる差異の画面を追加した。

## 自作サンプル

- 架空の検査記録をコードから描画。外部帳票・テンプレート・写真・ロゴ・個人情報は使わない。レイアウト・文言・数値・生成コードは本体と同じMIT Licenseで提供する。
- OpenCVの内蔵Hershey書体を使い、フォントファイルの追加取得・配布はしない。依存の既存の第三者通知は保持する。
- 数値80→85、DRAFT COPYの削除、CHECKEDの追加。既定設定で変更1・削除（推定）1・追加（推定）1を検出。
- 1100×650pxの入力A/B、JSON、HTML、ページ画像・切り出しを `docs/samples/readme/` に保存。入力ハッシュは生成JSONに記録する。
- 掲載用の日時と入力名以外は製品の比較コア・ReportWriter・HtmlReportWriterの標準出力。CLIの実行とも、日時・入力パスを除くJSONと全12枚のPNGが一致した。
- 別の出力先に再生成し、入力PNG・JSON・HTML・全出力PNGのバイト一致を確認した。
- Chrome 153の実際の重ね描き領域・差分一覧をREADME用に撮影。画面の描き足しや結果の加工はしない。
- 1280px／390pxで画像切り替え、キーボード操作、切り出しの読み込み、横幅、設定表示、JavaScriptなしの表示を確認。ページエラー0、外部リクエスト0。

[サンプル・出自・再生成手順](../samples/readme/README.md)。自作例はT2-7の実帳票受け入れを代替しない。

## ローカル検証

- .NET SDK 10.0.401、macOS Apple Silicon。Releaseビルド：警告0・エラー0。
- 全1,057件のテスト成功、失敗0・スキップ0。37ゴールデンとPERF-2jの追加34件を含む。
- CLI・JSON・アセンブリの版を0.1.2へ更新。CLIの `--version` は `reportdiff 0.1.2`。
- Windows x64自己完結・単一exeのpublishとバンドル検査に成功。exeは156,571,205 bytes。
- 必須ネイティブDLL 3件、PdfPig管理DLL 7件、既存依存・.NET 10.0.12・ライセンス原文を、既存の確認済みハッシュと照合する。FFmpeg・他OSのネイティブ資産を含まない。
- 最終ZIPは、コミットしたREADME・文書・サンプル・画面・許諾文と照合し、CRCと全ファイルのサイズ・SHA-256を確認する。ZIPとSHA256SUMSを公開し、再ダウンロードして原本と照合する。
