# v0.1.5 行整列・限定範囲のページ送り

2026-09-27。T3-1bのページ内行整列と、T3-1cの限定範囲のページ送り・文書集約を含むパッチ版。比較式・既定しきい値・依存バージョンは維持する。

- `rows.enabled: true` で文字層のあるPDFの行挿入・削除を整列し、構造変化と内容差分をCLI・JSON・HTMLへ報告する。領域・除外・PDF注釈・YAML出力の元座標を保持する。
- `rows.enabled` と `rows.carry_enabled` をともにtrueにすると、支持行・元帯の画素一致などが成立した隣接ページの送りを原因ごとに集約する。ページ別内訳・見送り理由・片側ページの未比較状態を残す。
- 両設定の既定値はfalse。送りも相違として扱い、条件が成立しない場合は通常の比較へ戻る。対応範囲は[設定説明](../CONFIGURATION.md#隣接ページへの送りと文書集約)と[限定範囲の受け入れ表](../TASKS.md#t3-1cの限定範囲の受け入れ表案a2026-09-27)を参照。
- 確認用raw overlayは補正前の原画像から生成し、判定結果から独立させる。READMEには重ね描き・差分一覧・確認用オーバーレイの3画像を維持する。掲載画面はv0.1.4で撮影したものと明記する。
- CLI・JSON／HTML・アセンブリの表示版を0.1.5にそろえる。Windowsの入力共有ロックを考慮したテストと、Release／逐次実行の両OS CIを含む。

同梱サンプルのHTML／JSONはv0.1.5で再生成し、相違3件を維持した。入力2PNG・出力13PNGは旧サンプルと全バイト一致し、実CLIの出力13PNGも一致。JSONは日時・入力パスと、直接ReportWriterを使う生成器では省略される行整列用サイズ3項目を区別して照合した。CLI側のサイズは入力の1100×650pxと一致する。READMEの3撮影画像は以前の版のまま維持し、今回ブラウザー操作を再実施したとは扱わない。
