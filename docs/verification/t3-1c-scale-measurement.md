# T3-1c A4・多ページの計測結果

2026-09-23、macOS arm64／.NET 10.0.12／OpenCV 4.13.0。**13条件・84プロセスでCLI全工程を測定し、計測による出力変化と見送り時の検出欠落がないことを確認した。一般的なA4入力での送り採用は未成立。** 製品の比較式・既定値・採用条件は変更していない。[計測設計](../planning/t3-1c-scale-measurement.md)、[機械可読記録](t3-1c-scale-measurement.json)を参照。

## 成立した範囲

- 通常CLI58プロセスと、タイマーだけを追加したコピー26プロセスを逐次実行。生成日時以外の全JSON／HTMLと全PNGが、同条件の製品・コピー・反復間で一致した。
- 13条件117ページ、元A/B・raw overlayの351組が送り有効／無効でバイト一致。見送り11条件の全ページDTOも一致した。
- 疎なType3対照は2ページで5→1、16ページで47→1。内容クラスタ0、実構造52件・リンク16組の参照、元画像から切り出した帯の画素一致を確認した。
- A4指定31ページは `flow_pixel_limit` で文書全体の送りを見送り、741件を維持して比較を完走した。30ページでは画素上限に達しない。
- 本文・送り帯の濃淡変更2例は、変更した矩形の中心を実クラスタが覆う。送り帯変更の例は範囲前提で見送っており、このA4例だけで帯検証の識別力を受け入れない。
- 対象26PDFのSHA256、全ページのMediaBox、本文の行数・文字列・順序を独立に確認した。通常／密／疎な入力の代表ページと最終ページをPNGで確認し、文字・罫線・固定部分がページ内に収まることを確認した。フォントは試験用の自作字形であり、読みやすさを評価する資料ではない。

製品99ファイルは、前回の全1,806テスト成功時のSHA256と一致した。今回は全テストを再実行せず、変更した検証ツールのビルド（警告・エラー0）、既存Type3 20PDFの再生成ハッシュ一致、新しい実CLI・独立監査を実施した。製品側の依存追加はない。

## 追加描画と時間の内訳

描画回数は計測コピーの `PdfReader.ReadPage` 呼出しで実測した。Skiaの2／8／16／30ページは4→12、16→48、32→96、60→180回。31ページは収集途中で予算超過となるため62→124回で、計画・採用評価へ進まない。疎な2／16ページは4→18、32→158回となる。

Skiaの実MediaBoxは595×842pt（約209.903×297.039mm）、ラスタは2479×3508px。30ページ新旧の累積は521,779,920px、31ページ新旧は539,172,584pxとなり、536,870,912pxの予算を62枚目で超える。128物理ページの件数上限を下回っても、画素上限が先に働く。

計測コピーの代表例では、Skia・48行・2ページのCLI内17.416秒のうち、従来の行比較が16.372秒、送り事前処理が0.470秒。疎な16ページのCLI内10.596秒では、送り事前処理6.836秒、最終の送り比較0.572秒、ページ保存2.477秒だった。事前処理の子段階である採用評価は3.351秒。親子のinclusive時間を二重加算しない。これらは各1回の段階観測であり、RSSの原因箇所を特定した計測ではない。

## 未成立のA4入力

採用期待が未成立だった条件は13条件中9条件。期待を変更して合格にせず、`expectation_unmet` として保存した。条件の詳細は機械可読記録と各 `result.json` に残す。

| 入力 | 観測した不成立 |
|---|---|
| Skia・24／48行 | 本文の描画端と一定間隔の境界が一致せず、候補の範囲・ページ写像が不成立 |
| Skia・描画端を0.12pt内側へ | 本文末尾の1px超過は解消したが、送り帯の全画素一致が不成立 |
| Type3・分数pt寸法 | 帯の全画素一致が不成立。対応行にも描画差を確認 |
| Type3・整数pt寸法 | 元帯・範囲は成立したが、改善率で文書全体を見送り。1ページ目は基準5,791pxに対し候補13,452px |

Skiaの元本文はY=400〜2801pxで、24行×100pxより1px長い。内側へした対照は400〜2800pxになったが、対応行には5,151pxの画素差が残った。整数ptのType3対照でも2組の対応行にそれぞれ2,244pxの差がある。生成時の本文が同じでも、描画された元画素まで同じとは限らない。この確認は判定マスクではなく、元A/Bの行を移動量100pxで対応付けて比較したもの。

疎なType3対照は594×840pt（約209.55×296.33mm）、2475×3499px、1ページ6行で、同じ大きさのキャンバス上の採用経路を測るための別入力。24／48行のA4帳票の代わりの合格例にはしない。分数pt対照は595.2×841.92pt、2480×3507px。これらの寸法差・描画差を丸め誤差として除去していない。

原画像の差がPDF生成・ラスタライズ・座標変換のどこで生じるかの切り分けは未完了。帯の全画素一致、改善率、元画素被覆、検出期待を緩める変更は行っていない。一般的なA4の送り対応は未受け入れのまま残す。
