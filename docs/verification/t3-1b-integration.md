# T3-1b：設定・CLI・レポートへの接続

2026-09-22。基準はv0.1.4（`6a899d1`）。[表示投影・構造変化](t3-1b-projection.md)の次工程として、承認済みの[行整列仕様](../planning/t3-1b-rows.md)と[内容比較面の補足仕様](../planning/t3-1b-common-surface.md)をCLIまで接続した。

**開発版では `rows.enabled: true` を指定してPDFの行整列を実行し、構造変化と内容差分をJSON・HTML・CLIから確認できる。最終受け入れは未完了。T3-1b全体の完了・コミット・配布物更新ではない。** 配布済みv0.1.4はrows設定に未対応。

## 接続した範囲

- rowsの9設定をYAMLへ追加。共通→帳票別のスカラー上書き、profile・`--no-regions`によるrowsの維持、未知・重複キー・型・範囲・最終DPIの検証を行う。専用CLIフラグは追加していない。全実効値はJSONとHTMLへ出す。
- 全体補正後に行推定を呼ぶ。語の矩形・ベースラインは全体補正を一度だけ適用し、クリップされた語があれば安全に見送る。元サイズ違い、完全一致、文字情報の上限、片側ページも理由を記録する。
- 採用時は内容比較面Cの判定を表示面Dへ投影した結果を保存する。DのA/B・判定画像・切り出しと、CのA/Bを分離し、JSONへ各座標と元A/Bの対応を出す。
- 通常クラスタ数を維持し、構造変化数・種類別内訳・総箇所数・網羅性を追加。CLI・HTML・compare-dirも総数を使う。構造変化だけで終了コード1。too_different・件数上限・未比較ページでは網羅性をfalseにする。
- 内容差分と構造変化のPDF本文を別々に注釈する。分割クラスタは各断片に交差する語だけを含め、断片間の語を混ぜない。除外は連続座標で適用する。
- 除外YAMLはDの各断片へ余白を付けて設定用A座標へ戻す。逆写像後も外側0.5mm丸め・クリップを行い、構造帯を含むひとつの外接矩形にはしない。
- 確認用オーバーレイと元カラー画像は補正前の入力を使う。行整列の有無・採否で画素を変えず、D画像と参照を共有しない。全体補正時の元B保存も維持する。

[SPEC 11.7](../SPEC.md#117-pdfテキスト層による行整列t3-1b)、[設定リファレンス](../CONFIGURATION.md#pdfの行整列)、[全設定例](../../examples/settings.yaml)、[有効化例](../../examples/rows.yaml)、READMEを同期した。5章の比較式、既定の検出／無視期待、固定174条件の入力・期待値は変更していない。

## 全回帰・互換性

Releaseビルド・既存試行ツールのビルドは警告／エラー0。全1,713テストが成功し、失敗・エラー・スキップ・未実行0（151.706秒）。行関連は345件。最終実行の集計・ハッシュは[機械可読記録](t3-1b-integration.json)に保存した。行関連の新規テストは42件（設定・座標16、実CLI24、断片の本文／YAML2）。既存174条件の比較面と期待値は維持する。

互換性は、前工程に記録したv0.1.4の95条件をrows無効／有効で実行して比較する。保存済みの基準出力も、前工程の全ファイルハッシュに再照合してから使う。生成日時、承認した追加のrows設定・行結果・集約件数、HTMLの行設定／結果欄、行ずれ見送り警告だけを除き、既存JSON値・HTML・全PNG・終了コードを照合する。rows有効用の一時設定パスとSHA-256は元設定の値へ正規化する。既存ケースで行整列を採用した場合は照合を失敗させる。

**95条件×2設定の190実行、1,684ファイル（PNG1,302枚）と終了コードが一致した。** 既存のPDF全体移動ケース1件のrows有効実行では、複数の帯が縦ずれを示すものの安全な支持が不足し、`ROW_SHIFT_SUSPECTED / insufficient_support`を追加した。判定・件数・全PNGは元の結果を維持している。全ファイルの照合記録は `out/t3-1b-integration-compatibility-final/verification.json`。

全テストと互換性照合は並行実行しており、実行時間を性能評価に使わない。テストログのPNG読込エラーは既存の壊れた入力の検証によるもの。

```bash

  --no-restore -c Release --disable-build-servers -m:1

  dotnet tests/ReportDiff.Tests/bin/Release/net10.0/ReportDiff.Tests.dll

  src/ReportDiff.Cli/bin/Release/net10.0/reportdiff.dll \
```

互換性ツールの出力先は新しいディレクトリを指定する。`out/`の記録・基準出力はローカル検証成果物でGit管理外。固定入力とソースのハッシュは機械可読記録に残す。
