## 候補選択

- 同じ高さの反復帯を、罫線・塗りを含むBGR全画素で比較する。挿入／削除側と、対応する他方の帯の両方が一致した場合だけ、先頭位置へ正規化する。同値な元位置の範囲と間隔を記録する。文字列が同じでも塗りが違えば統合しない。
- 行LCSの全経路を検査し、正規化後の写像と役割が同じ候補を統合する。非同値の65候補目で`resource_limit / hypothesis_limit`。別の有力候補に未解決の切断・再探索の曖昧さがあれば、検証できた候補だけで一意としない。既存の行／単語DP・追跡の上限も維持する。
- 単語の一致率は行LCSで予算内に計算した値を再利用する。候補数ぶん単語DPを再計算しない。列の矛盾を調べる語の対にも400万回の走査上限を設け、上限時は見送る。
- 各区間の整数dy再探索は、元Aと元Bの両方の固定した支持画素を評価する。候補間の比較も、全候補に共通する元の支持行とマスクを使う。BからAの除外へ写る画素は、いずれかの候補で除外へ入れば全候補で使わない。
- 候補の順位には、共通支持範囲のうち、少なくとも一つの仮説で対応が異なる行を両側から全て用いる。この集合は候補の点数を見る前に固定する。同じ対応の見出し等を加えて順位の差を薄めない。対応が固定された行も、各内容区間の支持数・インク量の検査には残す。共通画素で区別できなければ同点として見送る。式と`min_score_gap=0.02`は維持した。
- 列の矛盾は、同じ元行にある横に離れた語が、複数行で異なる移動を支持するかで調べる。ページ全体の外接矩形を使わず、固定の共通見出しによって列の矛盾が隠れることを防ぐ。
- 同じ横位置で3行以上連続して+1となる番号は、A/B双方にその並びがある場合だけ、列の恒久的な識別子として使わない。**数字は単語LCS・画素スコア・内容比較に残す。** 非連番の数値列にはこの扱いを適用しない。一般の数字削除・文字正規化は追加していない。

固定フッターの切断では、文字のない非白の縦罫線の切れ端は、そもそも独立した構造帯の候補にならない。純白余白または未対応の内容行という条件を満たす切断だけを比較する。罫線の濃淡変更でCに残る画素が変わる既存の反例は、引き続き`ambiguous / non_equivalent_safe_cuts`で見送る。

## 採否と領域

`RowComparer`は既存比較器の基準実行と、一意な最良候補のC上の実行を比較する。改善率は`(基準生差分数 - 候補生差分数) / 基準生差分数`。基準0と改善率不足は不採用とし、基準の比較結果をそのまま返す。採用した場合だけCの画像と結果を所有し、基準結果・不要な候補画像は解放する。CからDへ生差分を写して画素数が変わらないことも検査する。

無効、完全一致、画像入力・混在、元寸法の相違では、遅延取得するPDF行データを読まない。文字層なしと解析失敗は別理由にする。見送り時の状態・クラスタ・生差分／ラベルマスク・ノイズ・吸収・警告を基準と照合した。

除外・領域は、行整列前Aの矩形をDへ写し、元の宣言の優先順位で所有権を確定してからCへ集める。Cの各設定について全画像を比較し、最後に一度クラスタ化する。分類・移動検証が参照する除外も、写像済みの矩形列へ接続した。領域の監査値は現段階ではCの値。Dと元座標の出力、構造帯の除外状態、移動注釈のDへの変位変換は次工程に残す。

## 固定した期待と確認範囲

合成PDFは埋め込みType3フォント、300dpi、行高100px。参照用C画像は推定器を呼ばず、PDFを作った既知の行位置から直接転写して作る。採用結果を方向別の既存比較器のマスク・クラスタと照合する。

| ケース | Coreの結果 |
|---|---|
| R01／R03 | 挿入／逆方向の削除を採用。内容クラスタ0 |
| R02 | 採用。合計変更の内容クラスタ1を保持 |
| R04 | 2箇所の挿入・2段階のdyを採用。内容クラスタ0 |
| R05 | 固定フッターを採用。純白余白をCに残し、内容クラスタ0 |
| R06 | 全画素が等しい反復位置を1仮説へ統合して採用。100px間隔の同値位置を記録 |
| R07 | 採用。連番の変更4クラスタを保持 |
| R08 | `no_text`で見送り |
| R09 | `column_conflict`で見送り。非連番の数値列でも同じ理由 |

全ケースで逆方向も確認した。採用ケースのA/B交換では写像の元範囲が交換され、選択スコアも一致する。R系の構造変化の件数・CLI終了コードの受け入れは、出力経路の接続後に確認する。

追加の安全網：

- 挿入と同時の全語置換・小数点・マイナス。方向別の参照マスクとクラスタが一致し、全語置換／マイナスは各2クラスタ、小数点は1クラスタ。単一の帯を削除＋挿入と見なして変更を外さない。
- 同じ文字で異なる塗りの反復候補は複数のまま。入力語の列挙順を逆にしても代表位置・同値範囲・スコアを維持する。
- 66反復行に異なる全画素パターンを持たせ、65番目の非同値候補で見送る。候補を間引かない。
- 内包したcompare領域、複数のdiff、領域除外、旧exclude、挿入／削除をまたぐ設定。元の物理対象に対応する設定から作った所有マスク・除外・内容差分・分類・抑制値が一致する。
- 合計値だけを除外した実PDFの両方向でも整列を採用し、内容クラスタ0と除外画素数を確認する。
