## エージェント側で実操作ができなかった理由

Codex In-app BrowserでV04-01のローカルHTMLを開こうとしたが、読み込み前にブラウザーのURLポリシーが `file://` を拒否した。ツールの返答は「The requested URL protocol is not allowed. Allowed protocols: http:, https:.」。同じページへの回避経路・別ブラウザー等による迂回も禁止されたため、代替経路でのアクセスは試みていない。これはブラウザー機能の制約であり、ReportDiffの画面不具合やテスト不合格の検出結果ではない。

エージェント側のブラウザーで開けた対象は0件、実操作合格も0件。画面の描画・画像表示・クリック・折りたたみをエージェントが確認したとはしない。[T3-1bの過去の代理確認](t3-1b-browser-handoff.md)とは別に、上記の今回のユーザー報告を根拠としてV-04を完了にした。V-04全体を未確認のまま保留する案は採用していない。
