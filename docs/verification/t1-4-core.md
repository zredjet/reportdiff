## 構成

- `ReportDiff.Core`：単位換算、比較パラメータ、候補抽出、位置ずれ吸収、除外領域、クラスタ化。入出力は `Mat` とレコード型で、ファイル・PDF・コンソールには触れない。
- `ReportDiff.Cli.ConfigurationLoader`：YAML の設定読み込み。未知・重複キー、形式、範囲、非有限値を日本語のエラーとして拒否する。優先順位は既定値、設定ファイル、明示したプロファイル、明示した DPI の順。`image_dpi` が未指定なら最終的な `dpi` を使う。
- `PageComparison` / `RawDifference` は返したマスクを所有するため、呼び出し側で `using` によって破棄する。入力 `Mat` は変更しない。
- `tools/ReportDiff.Benchmark`：合成データだけの手動計測用プロジェクト。アプリのソリューションには含めない。

プロファイルが上書きするのは `max_shift_mm` と `edge_tolerance` のみ。設定の `min_pixels` と `max_clusters_per_page` は 1 以上、`max_diff_ratio` は 0 より大きく 1 以下とし、DPI・mm・許容値は SPEC 7 章の範囲で検証する。

## 最適化

Lab・ぼかし・局所コントラストはページ全体で一度だけ作る。候補に触れるインクからグループを作り、外接矩形と余白 `s+3` px の範囲に探索を限定する。特徴量を元のページ座標から参照し、画像端は複製することで、切り出し境界に由来する差を避ける。

探索順は `|dx|+|dy|`、`dx`、`dy` の順。現在の最良値以上の差分数になった候補は評価を打ち切り、0 になったグループは探索を終了する。全ページ・全ずれの元の処理は、内部の検証・計測経路として残している。

## A4・300dpi の計測

環境：macOS 26.5.1、Apple Silicon / ARM64、論理 CPU 16、.NET SDK 10.0.401 / Runtime 10.0.12、Release 構成。

2480 × 3508px に Hershey の数字を 20 列 × 30 行（600 文字）配置。中央付近の 1 文字を 0 → 8 に変更し、ずれありのケースは B 全体を横・縦にそれぞれ +1px 移動した。画像生成・ファイルの入出力・PDF レンダリングは計測対象外。各方式を 1 回ウォームアップし、3 回の中央値を採用した。

| ケース | 最適化前 | 最適化後 | 判定 |
|---|---:|---:|---|
| 完全一致 | 5.9ms | 5.2ms | same、クラスタ 0 |
| 1 か所変更 | 1096.6ms | 225.8ms | different、クラスタ 1 |
| 1 か所変更＋全体 1px ずれ | 1117.0ms | 245.4ms | different、クラスタ 1、吸収 599、最大ずれ 1px |

最適化後はいずれも目標の 2 秒以内。全ケースで最適化前後のマスクも完全一致した。変更を含むケースの生差分はどちらも 204px。

最適化後の中央値に対応する内訳（ms）：

| ケース | 前処理 | 候補抽出 | グループ化 | ずれ探索 | 除外・クラスタ化 |
|---|---:|---:|---:|---:|---:|
| 1 か所変更 | 105.0 | 36.3 | 58.1 | 5.8 | 20.2 |
| 変更＋1px ずれ | 105.8 | 40.7 | 58.1 | 20.0 | 20.7 |

全サンプルと実行環境は [計測 JSON](t1-4-a4.json) に保存した。これは合成画像での比較コアの計測であり、Windows 実機・実帳票・入力から出力までの性能確認ではない。T1-1〜T1-4 の新しいコードは Windows CI では未実行。

## 再実行

macOS は [ネイティブ依存の準備](../NATIVE_RUNTIME.md) を済ませてから実行する。

```bash
dotnet build
dotnet test
dotnet build tools/ReportDiff.Benchmark -c Release
mkdir -p out/benchmarks
dotnet run --project tools/ReportDiff.Benchmark -c Release --no-build -- 3 > out/benchmarks/t1-4-a4.json
```

テスト用の PNG と期待値はビルド時にテストの出力ディレクトリにコピーされる。計測回数は最後の引数で指定する（既定 3 回）。
