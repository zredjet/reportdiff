# T3-1c：文字候補と構造帯の独立検証

2026-09-22。[検証方針](../planning/t3-1c-candidate-inference.md)に従い、正解の行ID・帯座標を推定器へ渡さず、PDFの文字層と描画画素から候補を求めた。**R10・R11・3ページ連鎖の送り帯と構造帯の範囲が一致した**。条件外のページは元の比較を維持する。製品の自動送り・文書集約には未接続で、T3-1cは未完了・未コミット。

## 確認した範囲

既存20PDF・44ページのハッシュを固定し、本文位置・行間隔を変えた入力、固定部分の支持不足、対応本文の変更を含む12PDF・26ページを追加した。すべてType3の合成入力で、一般の帳票やSkia生成PDFへの適用実績ではない。追加26ページはPopplerで描画し、改ページ・罫線・固定部分・灰色文字がページ内に収まることを確認した。

16組をA/B両順序で実行し、3ページ連鎖のp1のみ／p1,p3のみの4実行を加えた。合計36実行。選択ページ以外を描画せず、p1とp3を隣接扱いしない。

推定器は`PdfTextReader`と`TextLineLayout`の行を使う。対応する2ページ以上から位置・文字・画素が共通する両端の部分を調べ、その間の全非白画素から本文端を求める。複数の一意な行の変位から送り高を求め、隣接ページの本文先頭と照合する。候補の帯が全画素一致した場合だけ、元ページの帯置換を両端・両順序・3プロファイルで検証する。

`CandidateInference`と`CandidateSurface`は生成器を参照しない。実行ドライバーはmanifestの入力名とハッシュだけを読み、正解座標は実行後のPython照合器だけが参照する。送り帯は全幅を使い、除外・薄色しきい値・差分0になる切断位置の探索は行わない。

## 結果

| 入力 | 候補・比較面の結果 |
|---|---|
| R10、R11、3ページ連鎖 | 正解5帯を両順序で推定。14対応ページのCでnormal／strict／looseとも生差分0 |
| 本文位置350px・間隔125px、400px・150px | 正解5帯を両順序で推定。125px間隔の最終ページ2種類は本文の高さが1px長く、両順序で比較面を見送り |
| 送り帯の文字変更／同文の濃淡変更／帯端の濃淡変更 | 文字不一致または全画素不一致。送りを確定せず元の差分を維持 |
| 帯の直前の濃淡変更 | 全非白画素を含めるため本文上端が300→298pxとなる。切断を動かして一致させず、元の差分を維持 |
| 同名の反復行 | `repeated_body_text`。一つの候補を選ばず元の差分を維持 |
| フッターなし、1→2ページ | 固定部分の支持不足。候補を作らず、片側ページの全内容を確認済みにしない |
| p1,p3のみ／p1のみ | 候補なし。選択外のp2を読まず元の差分を維持 |
| 送り帯外の対応本文の濃淡変更 | 送り帯の一致後も、Cにnormal／looseで1,390px、strictで2,070px・各1クラスタが残る |
| 挿入帯の直後にある対応帯の境界変更 | Cにnormal／looseで60px、strictで68px・各1クラスタが残る |

検証済み画像帯は両順序を含め28件。このうち24件は、両端がCから外した構造帯と正確に一致するか、片側ページ上の検証済み範囲として追跡できた。残り4件は画像帯自体は一致するが、一方のページの比較面が作れず**範囲対応未成立**。`band_verified`だけを`carried`と解釈してはいけない。

125px間隔の一部の最終ページでは、4行に対する本文の画素範囲が500pxでなく501pxになった。余分な1pxも非白画素であり、削って成功扱いにしていない。R11の150px間隔は全対応ページで比較面を作れた。文字座標の行間隔は、各座標を丸めてから引くと124/125pxが混在するため、変位を計算してから丸める。描画された本文端はこの丸めで補正しない。

## 元画素の帰属と片側ページ

構築できた36比較面について、表示写像DがA/Bそれぞれの元画像の全行をちょうど一度覆うこと、比較面Cの画素が元画像と一致すること、Cにない元画素が記録した構造帯だけであることをPythonでも検査した。片側の純白余白をCに保持し、非白の余白を切り捨てない。送り由来の省略範囲は側・物理ページ・開始位置・高さを画像検証済み帯と照合する。途中の挿入行は前後それぞれ2行以上の支持を必要とし、送りとは別の構造帯として残す。

R11の追加ページでは、検証帯と全ページで一致する固定部分の外に非白画素が残らなかった。追加の薄色塗りがあるケースでは、帯外の**3,570画素**を未確認として残し、ページ全体の注記条件を満たさなかった。どちらも`only_in_a/b`と`difference_count_complete=false`を維持する。固定部分の画素一致は、固定部分という意味の一般的な保証ではない。本文がページ両端で反復するケースは別途必要。
