# 同一ページ二原因の支持境界

2026-09-23。[事前設計](../planning/t3-1c-same-page-support.md)に従い、元の `same-page-two` を含む15ケース30方向を検証した。十分な支持を持つ12方向は既存製品で集約でき、負例16方向は見送りとなった。元の正例2方向は未成立のまま残す。製品104ファイル・採用条件・SPEC 5章の比較式・検出期待は変更していない。

## 候補と製品の区別

`between-short` と `faint-support` の4方向は範囲の写像だけが成立する。候補C/Dには各7構造があるが、前者は `insufficient_support/support_bands`、後者は `insufficient_support/support_ink` で第1ページの採用を拒否する。第2ページの評価が成功しても文書全体を基準比較へ戻し、製品件数はそれぞれ14・11を維持する。

この候補7件をCLIの正解に置き換えない。プローブのログも `candidate` と `product` を分け、保存した候補内訳・範囲成立・採用結果・製品結果を別々に記録する。見送り18方向のページJSONは送り無効時と一致し、全30方向の元A/B・raw overlayのPNGは有効／無効で全バイト一致する。
