# T3-1c 数値変更を含む行対応の製品接続

2026-09-23。[承認済みの接続案](../planning/t3-1c-numeric-correspondence.md#製品接続の具体案)をCore・CLI・JSON／HTMLへ接続した。同じ物理ページ内の数値変更を含む行対応に限定し、元の文字と画素を保持する。数値の許容誤差、比較しきい値、送り帯の全画素一致、採用の支持条件は変更していない。ソース・固定入力・証拠のハッシュと集計は[検証JSON](t3-1c-numeric-cli.json)に記録する。

## 接続した条件と証拠

`PageFlowNumericRows` は元本文と別の型で行IDを持つ。同じページ、両側で一意な数値欄以外のラベル、二つ以上の非数値トークン、直近二行の元本文の完全一致と同じ相対位置を要求する。ASCIIの符号付き整数・小数の空白区切りトークンが対象。文書全体の元本文の一意性と共通順序、全ページ対応、選択範囲の省略がないことも必須とする。

行IDはC/D写像、同じページ内の対応済み候補が送りでない証明、実構造と原因の所属に使う。元本文を差し替えず、`PageFlowInference` と `PageFlowAdoption` の元本文による推定・支持評価を維持する。局所構造帯の前後の支持にも、数値変更行を加算しない。数値行の全幅・全高を内容比較へ残し、クラスタを一行一件へまとめ直さない。送り帯の文字・画素が変わった場合は数値対応で救済しない。

証拠は文書記述と行配置に結び付ける。根拠行の欠落・重複・文字／位置／順序の変更、別文書・別配置への流用を拒否する。保持時の固定費256Bとページ配置参照あたり8B、対応一組2,048Bと変更トークン位置あたり4Bを既存64MiB記述予算へ加算する。非送り証明と合計してちょうど上限／1B超過を確認し、超過時には両方の証明を破棄する。記述予算はプロセスRSSの上限ではない。

Gの数値行・根拠行をOの全幅帯へ完全に戻してJSON／HTMLへ記録する。`page_flow.numeric_matches` は証拠がある場合だけ追加し、元本文・元座標・0始まりの変更トークン位置・根拠二行を持つ。`status: applied / not_applied` で写像への使用と見送りを分け、`pixel_equality_proven: false`・`used_as_exact_support: false` を明記する。HTMLの元本文はエスケープする。raw overlayは引き続きOの元画像だけから生成する。

内容クラスタ計30件、C/Dの224画像、原因グループの実構造ID・収支を固定した独立証拠へ照合した。元本文だけの支持評価は、スコア・支持数・採否を含め事前の独立結果と一致。数値の対応証拠32組を元本文・元座標・根拠行へ照合した。未採用候補Cの内訳を製品の採用件数には使っていない。

文字と罫線が薄い `weak-actual-support` は、対応と写像を作れても元本文による支持が `insufficient_support / support_ink` となり、両方向とも採用を見送った。未採用候補の6件ではなく、通常比較の7件を維持した。変更行を一致行として数える誤採用の反例は、[事前検証](t3-1c-numeric-correspondence.md#支持の取り違えを防ぐ対照)に保存してある。

反復ラベル、非数値ラベル変更、桁区切り、英数字ID、数字だけの行、近傍根拠不足、行順入替え、隣接する二行の変更、送り帯の数値／文字／画素変更は見送る。挿入なしの数値変更は通常比較の1件を維持する。見送り時のページ結果全体は送り無効時と一致し、部分的な原因グループを残さない。

旧新の送り無効時は、日時以外のJSON／HTML／PNG **1,936ファイルが一致**。新CLIの送り有効／無効で、元A・元B・raw overlay **324組が全バイト一致**した。すべて相違の終了コード1を維持した。

## 設定と保護

明示的な全ページ／一部ページ選択、本文の除外・exclude領域、根拠行不足、支持インク上限、改善率上限、文字収集上限では通常比較へ戻る。比較領域と `--no-regions` による除外無効化では数値変更を内容比較へ残す。compare-dirは共通の `rows.enabled` と帳票別の `carry_enabled` を継承し、一覧と個別結果に6件／集約後2件を表示する。

入力PDFが検証中に変わった場合と元帯PNGの保存失敗は終了コード2とし、`--force` の旧出力を保持してステージングを削除する。HTMLの新しい元本文欄のエスケープも検証した。追加テストの初期失敗とログは保存し、修正後の結果とは区別する。ブラウザー操作・画面サイズ・JavaScriptの保留はこの検証で合格にしない。
