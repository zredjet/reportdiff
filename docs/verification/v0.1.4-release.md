# v0.1.4 ページ進捗・確認用共通色

2026-09-22。最優先で承認された T3-7・T3-6a を含むパッチ版。比較式・判定の既定しきい値・依存バージョンは維持する。

- CLI に処理中のページ順／対象数を表示する。通常の端末では同一行更新、ログ・パイプ・狭い端末では改行出力。一括比較はファイル名を併記し、quiet は進捗と完了要約を抑止する。[進捗の検証](t3-7-console-progress.md)。
- 確認用オーバーレイの共通成分を既定の薄いグレー `#CCCCCC` にする。`report.raw_overlay_common_color: "#RRGGBB"` で変更でき、黒指定で従来画像を再現する。PNG と HTML 凡例・実効設定・方式名を同期する。[共通色の検証](t3-6a-overlay-common-color.md)。
- CLI・JSON・アセンブリ・README・同梱レポートの版を 0.1.4 にそろえる。自作サンプルの再生成 17 ファイルが一致し、実 CLI との JSON（日時・入力パスを除く）と全 13 PNG が一致した。既定設定で 3 箇所の相違を維持する。
- 掲載画面は v0.1.4 の実際の HTML から撮影。Chrome 1280 / 390px、JavaScript 有効／無効、キーボード、PNG 単体、横幅、外部通信 0 を確認した。

ローカルの最終 Release ビルドは警告・エラー 0、全 1,368 テスト成功、失敗・スキップ 0。Windows publish の事前検査で必須 DLL・PdfPig・ランタイム構成と FFmpeg 非同梱を確認した。

## 配布と公開

公開対象コミットの Windows x64／macOS Apple Silicon CI が成功した後、同じコミットを展開したクリーンなソースから Windows の自己完結・単一 exe を発行する。[配布手順](../DISTRIBUTION.md)に従って埋め込み版、必須 DLL・依存・許諾文のハッシュ、ZIP の CRC・全ファイルのマニフェスト、同梱文書と対象コミットとの一致を検証する。

ZIP と SHA256SUMS を公開し、GitHub からの再取得で原本との一致を確認する。公開対象コミット・両 OS の CI 件数・ZIP のハッシュと公開後の確認結果は [v0.1.4 リリースページ](https://github.com/zredjet/reportdiff/releases/tag/v0.1.4) に記録する。ローカルのログとアセットは `out/releases/v0.1.4/`。

Windows の完成版 exe をユーザーの PowerShell／cmd で実行する確認、Windows の Edge／Chrome、低メモリ実機、実帳票の受け入れは未完了。macOS／PTY／CI の検証と分けて管理する。exe は未署名、Intel Mac は対象外。T2-8 の保留分と T3-1b 以降の行整列は今回の完了範囲に含めない。
