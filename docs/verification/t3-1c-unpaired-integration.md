# 末尾の片側ページと独立原因：限定した製品接続

2026-09-26。[承認済みの接続範囲](../planning/t3-1c-unpaired-components.md)をCore・CLIへ実装した。追加採用は末尾1枚の片側ページと、互いに交わらない単一原因のページ群に限定する。新規8方向の実CLIが事前診断と一致し、片側ページの未比較とraw evidenceを保持する。T3-1c全体の受け入れ・コミットは未完了。

## 製品で成立した範囲

[事前診断](t3-1c-unpaired-components.md)の16ケース32PDF・111物理ページを、バイトを変えず[固定入力](../../tests/ReportDiff.Tests/Fixtures/page-flow-unpaired/README.md)へ追加した。各ケースをA→B／B→Aで実行する。

| 入力 | 接続前CLIの未集約→集約 | 接続後CLIの未集約→集約 | 保持する内容 |
|---|---:|---:|---|
| 独立二原因と末尾ページ | 19→19 | 11→2 | 内容0、実構造11 |
| 別群で挿入／削除が併存 | 19→19 | 11→2 | 個別の符号・ページ別収支 |
| 二群の間に中立ページ | 19→19 | 11→2 | 中立ページに構造を作らない |
| 独立二原因と濃淡変更 | 19→19 | 12→3 | 実PDFの生差分2,462px・内容1 |
| 既存の単一R11 | 6→1 | 6→1 | 従来経路を優先 |
| 既存の3→4ページ連鎖 | 9→1 | 9→1 | 従来経路を優先 |

新規8方向は各2グループ・実構造11・片側ページの補助帯1。各グループの原因・全実構造参照・リンク・補助帯・収支を、保存済みの独立診断へ一致させた。非送り候補は元IDを保持する。逆符号のA→BではID4、その他ではID2となるため、ID2へ固定せず診断の元IDを照合する。

片側ページは `only_in_a/b` のままで、クラスタ／実構造を作らず、両方の網羅性をfalseのまま保持する。帯外の3,570pxやBGR(254,254,254)の30px、固定部変更、555→556の跨ぎ、反復本文、同一連鎖の二原因、未接続の余分な末尾ページは見送りを維持した。二原因と帯外残余の一部は規則的レイアウトの前段で止まるため、後段の残余検査を実行した証拠と混同しない。

## 証拠・設定・上限

`PageFlowTerminalScope`を文書・凍結済みレイアウト／候補・実効設定へ結合する。通常の公開集約APIだけでは追加経路を使えない。既存の成功を優先し、全ページ選択なし、300dpi／normal相当、補正・数値対応・除外・領域なし、連続したページ列、対応ページ2枚以上、片側は末尾1枚を要求する。

境界を跨がないことが証明された候補だけを非送りとし、元帯の全画素一致・各ページのC/D・支持・改善率を維持する。構造が欠落／重複した場合や一群でも収支が不成立なら全グループを取り消す。未対応ページの完全性を呼出元がtrueとしても、計画で確認した未比較へ戻す。

非送りの索引・証拠と、成分分割の索引・局所入力・結果参照は、[確保前の計上式](../planning/t3-1c-unpaired-components.md#製品接続の証拠資源契約)を同じ64MiBの残りへ適用した。新規管理データだけであり、Matや共有の可変カウンターを追加していない。A/B両方向で、予約ちょうどは成功、1B不足は全追加証拠または全グループを取り消し、再試行しても残量を累積消費しない。

集約だけの予算不足は、採用済みC/D・未集約11件を保持して `terminal_descriptor_limit` とする。非送り証明の予算不足は `flow_descriptor_limit` として従来比較へ戻す。別文書・候補・レイアウトへの証拠流用、行本文差替え、選択範囲や片側残余確認の取消も拒否した。

CLIではstrict／loose、別DPI、明示的な全ページ選択／飛び飛び選択、補正有効、除外、領域、支持数の増加・最大区間数の縮小・取得語数上限の縮小を検査し、見送り時の全ページが無効時と一致した。normal同値の明示と無効領域は採用する。濃淡変更へ最低改善率1を要求した場合も従来比較を保持する。入力変更・画像保存失敗では既存レポートを保護した。

## 独立照合と既存互換

- 固定32方向の有効／無効64プロセス。追加採用8方向以外と無効時の計3,010ファイルが接続前の保存結果と日時以外一致。全方向の元A/Bとraw overlayの384画像組がバイト一致。
- 接続前の実行ファイルを別保存し、既存58方向を旧新116プロセスで比較。全4,916ファイルが日時以外一致し、raw画像480組もバイト一致。全ページ対応・単一R11・縦補正・数値対応・共有原因・元ページ保持面の正例／上限を含む。
- 診断ツールを接続後の製品計画にも照合する形へ更新し、32PDFを別生成して再実行。入力ハッシュ、52ページのPython参照、C/Dカラー208画像・マスク104画像、元帯60組、実構造142件、全32方向の採否・件数を再確認。診断側の期待や式を製品結果へ合わせて緩めていない。
- フォルダー比較は末尾二原因・濃淡変更・薄色残余の3対。相違3・エラー0、11→2／12→3／19→19を一覧と子レポート間で照合。網羅性falseを保持する。共通／帳票別設定の継承も回帰テストで確認した。
- 固定入力のHTML3,466リンクとフォルダー比較448リンクについて、参照先・ID重複・外部参照なしを静的検査した。ブラウザー操作、画面サイズ、JavaScript条件は保留のまま。
