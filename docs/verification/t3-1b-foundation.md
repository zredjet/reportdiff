2026-09-22。基準は v0.1.4（`6a899d1`）。[補足仕様](../planning/t3-1b-common-surface.md)の提示後に受けた作業続行の指示を承認として、最初の実装工程を進めた。T3-7 の進捗表示、T3-6a の共通色設定は維持する。

## 実装した範囲

- `RowComparisonSurface` は、全体補正後の入力と、支持済みの帯の役割を受け取る。両入力の全行を順序どおり一度ずつ扱い、明示した構造帯だけを内容比較面 C から外す。非白というだけで構造帯に変換する処理はない。
- 全チャンネル255の片側余白は C に残す。薄い塗り、誤った役割、重複した白余白の対応、同じ隣接点での両側内容の削除、不完全な元行の被覆、整数で表現できない寸法を拒否する。
- C の全行について、設定された近傍が A/B の少なくとも一方の実在する連続範囲で裏付けられることを確認する。領域の実効探索幅も含む最大半径を使う。画像端には元画像の同じ端を要求し、生成した白い詰め物を根拠にしない。
- C / D のマスク転写、領域所有値などの型を保った転写、クラスタの実画素に基づく帯別矩形、生成した白側の null、全体補正前への座標復元を追加した。`PageMap.MapBoundsParts` を追加し、従来の外接矩形の演算と通常経路の割当を維持した。
- PDF から `Letter.StartBaseLine` / `EndBaseLine` を取得し、Core へ PDF 型を含まない単語データを渡す入口を追加した。文字の整理と先頭語による行の重なりを既存注釈と共用する。回転・UserUnit・描画寸法・非水平文字・取得上限・解析失敗は部分的な行データを返さない。
- 行のベースライン中央値、対称な単語 LCS、行 LCS の対応列挙、区間内の画素再探索・支持数／インク量・安全な切断の初期処理を追加した。これは一つの仮説を構築する内部処理であり、ページとしての採用判断ではない。

比較式、特徴量、二段目、クラスタ化、参照実装、既存のゴールデン期待値は変更していない。

## 固定した安全網

前回の独立試行で成功した174条件を `tests/ReportDiff.Tests/Fixtures/row-surfaces/` に固定した。自作 PNG は SHA-256 ごとに共有する44ファイル、合計978,719 bytes。既存42ゴールデンの画像は既存ファイルを直接参照する。期待統計・全生差分マスクの SHA-256 は当時の Python 参照結果を保存し、今回の製品出力から再生成していない。

全174条件で、基準の C 入力 A/B、方向別の全生差分マスク、状態、ノイズ、吸収数、最大ずれ、クラスタの矩形／画素数が一致した。元画像を変えず、A/Bと写像の交換で入力が対応し、C→D→Cでマスクと画素数を保持する。これは既知の正しい帯に対する安全網であり、R01〜R09の行推定の受け入れではない。

追加の検査を合わせた行関連テストは218件。次を含む。

- 4pxしか離れていない逆向きの切断を両方向で拒否。40px離した対照は既定半径で通り、領域の探索幅を広げると拒否する。
- 純白と255未満の1チャンネル差、欠落／範囲外の元行、設定範囲の両端、非有限値、寸法の整数限界。
- Cで8画素の1クラスタがDで4画素ずつの2断片になっても、Cの1件を維持するための写像。Dで再クラスタ化すると両方がノイズになる対照も固定。
- Cで40%の生差分を `too_different` とし、Dで詰め物が増えて20%になっても判定し直さない。
- 元A/Bの断片座標、片側の null、全体補正との合成、CV_32Sの領域所有値の転写。
- 合成PDFの1行挿入／削除と、合計の変更を加えた各方向。ベースラインとLCSから帯を作り、内容クラスタ0／1を確認。構造変化の2／3件という出力契約はまだ未検証。
- 反復行のLCSの重複しない列挙、行／単語DP・探索の上限、PDF文字取得の見送り、rowsの値検証。

## 切断位置の一意性

同じ行ずれであっても、複数の安全な切断位置によってCへ残る画素が異なる場合がある。灰色罫線の6×2pxの濃淡変更を含む合成PDFでは、任意の一つを選ぶとその変更が挿入帯へ入る恐れがある。支持点とずれ量は同じであり、画素の違う候補を同値として扱う根拠にはならない。

この場合は `ambiguous`、detail=`non_equivalent_safe_cuts` として候補を返さない。両方向のテストを追加し、従来比較に変更が残ることを確認した。検出の期待を緩めたり、生差分を消す対策ではない。初期処理における「一候補の内部でも一意でない」検査であり、後述の競合仮説全体の選択は未実装。
