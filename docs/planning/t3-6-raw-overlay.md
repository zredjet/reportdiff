# T3-6 判定から独立した確認用オーバーレイ

対象は [TASKS の T3-6](../TASKS.md)。ユーザーの赤 A／青 B／黒・グレー共通という要望と、T3-4a の次へ進む指示に従い、タスク案の推奨方式を具体化する。T2-8 の保留分は残す。

状態：2026-09-22、実装・検証済み。以下は導入時の仕様。共通色の設定化と表示式の更新は [T3-6a](t3-6a-overlay-common-color.md) を参照。[確認結果](../verification/t3-6-raw-overlay.md)を参照。

## 表示方式

同じ DPI の入力 A/B を、比較用の全体補正を行う前に使う。左上を合わせ、サイズ差は右・下だけ白で埋める。画像入力も PDF のラスタライズ結果も同じ処理へ渡す。

8bit RGB に対して `g = (299*R + 587*G + 114*B + 500) / 1000`（整数除算、四捨五入）とし、出力 RGB を `(gB, min(gA,gB), gA)` とする。方式名は `grayscale_red_blue_v1`。しきい値・平滑化・ガンマ変換は加えず、アンチエイリアスの濃淡を残す。A のみ赤、B のみ青、同じグレー値は黒／グレー、白同士は白になる。グレー値が等しい色相差は見えないため、元カラー A/B も確認できるようにする。

生成関数は正規化した補正前画像だけを受け取り、比較結果・マスク・除外・プロファイル・分類・テキストを参照しない。出力画像は一ページごとに生成・保存・破棄し、グレー変換の作業領域は行単位にする。

## 有効化と保存

- `report.raw_overlay: false` を既定とする。共通 YAML → 帳票別 YAML の部分上書き → `--raw-overlay` の順に適用する。CLI は明示有効化のみ。無指定では YAML を尊重する。compare / compare-dir 共通。
- 実効値を個別 JSON の `config.report.raw_overlay` と HTML、CLI 指定の有無を一覧 JSON に記録する。既存 schema_version は 1。
- 有効時は選択された全ページで作る。same・too_different・除外済み・片側のみも対象。`--save-all-pages` は不要。`--no-html` でも PNG/JSON を保存する。
- `pages/p001_raw_overlay.png` と `pages[].raw_evidence` を追加する。メタデータには方式名、`original_top_left` 座標系、DPI、白埋め後のキャンバスサイズ、各側の欠落フラグ・元サイズ・右下の白埋め量・画像パス、オーバーレイパスを記録する。
- 確認用 A/B は元カラーを保った白埋め後画像。既存 `images.a`、未補正時の `images.b`、補正時の `images.b_original` が保存されていれば共有する。既存画像がない場合のみ `_raw_a.png` / `_raw_b.png` を追加する。既存 `images` の値・保存条件は変えない。
- 片側ページは欠落側をキャンバス全体の白画像として保存する。欠落側の元サイズ・白埋め量は null、missing は true。元画像のある側は既存 PNG を共有する。判定・集計・終了コードは従来どおり。
- 無効時は確認用画像も raw_evidence 項目も追加しない。保存エラーは既存の ReportWriteException と staging/commit の扱いを使い、`--force` でも旧結果を保持する。

## HTML

有効なページに「確認用オーバーレイ（補正前）」を別枠で追加する。初期表示は赤青画像。元 A/B に切り替えられ、凡例と「判定とは独立」「左上合わせ・補正前」「色相差は元カラーを確認」という説明を常時表示する。既存ビューには判定表示の見出しを付けて区別する。JavaScript なしでも PNG へのリンクから全画像を開ける。切り替えで集計・状態を変更しない。

## 確認範囲

固定画素・白・黒・グレー・濃淡・色相差・1px ずれ・反転・非連続 Mat、設定合成、CLI の全状態と PDF/画像/片側/サイズ差/ページ選択/HTML 省略、プロファイル・除外・全体補正に対する画像不変性、有効／無効での既存出力不変性、書き込み失敗時の旧結果保持を検証する。42 ゴールデンを含む全テスト、Chrome file:// の 1280/390px・キーボード・JavaScript 無効、A4 300dpi の追加時間/RSS/サイズ、Windows 配布物の静的検証を行う。Windows 実行・ブラウザ実機は未確認として残す。
