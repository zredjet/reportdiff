# T2-5 フォント非埋め込みの警告：仕様・実装計画

状態：2026-09-21、仕様案提示後の「次タスクに進めてください」を受け、推奨案で実装を進める。開始点は `a66761b`（T2-4a）。実装・検証済み。[確認結果](../verification/t2-5-fonts.md)を参照。このタスクのローカルコミットまでで停止し、T2-6 と push は行わない。確定仕様は SPEC 11.5 節。

## 推奨する動作

選択した PDF ページの使用フォントを調べ、埋め込みがないと確認できた場合に `NON_EMBEDDED_FONT` を JSON と HTML の警告一覧へ出す。対象は A/B の両方で、相違なし・クラスタなし・差分上限超過・片側だけのページも含める。画像入力と未選択ページは対象外。PDF テキスト注釈の有無、回転や件数による注釈の省略、全体補正の有無から独立させる。

警告によって画像の描画、比較マスク、分類、クラスタ数・位置、同一／相違、終了コードを変えない。フォントの取得・埋め込み・置換は行わない。

### 使用フォントと判定範囲

- 既存の PdfPig 0.1.16 がページ本文と実行された Form XObject から取得した文字要素を起点にする。空白や不可視文字も使用に含める。リソース辞書に登録されているだけのフォントは非埋め込み警告の対象にしない。
- フォント名で辞書を推測せず、元 PDF のオブジェクト参照で対応付ける。同名でも別辞書は区別し、同じ辞書をページ内で繰り返し使った場合は重複警告を出さない。
- フォント名は元の辞書の `BaseFont`、Type3 は `Name` を優先する。PdfPig が内部で代替したフォントの名前を元の名前として報告しない。名前を取得できない場合は名前不明と記す。
- 埋め込み判定は PDF 内のフォントプログラムの所在の確認であり、プログラムの全字形の正しさ、利用許諾、OS 間の描画一致の保証ではない。

| PDF の種類・状態 | 推奨する扱い |
|---|---|
| Type1 / MMType1 / TrueType | FontDescriptor の FontFile / FontFile2 / FontFile3 を解決し、対応する埋め込みストリームの有無を確認する |
| Type0 | DescendantFonts の CIDFontType0 / CIDFontType2 の FontDescriptor を調べる |
| Type3 | CharProcs の字形プログラムが PDF 内に定義される方式として扱う。FontFile がないことだけで非埋め込みにしない。定義を確認できない場合は判定不能 |
| サブセット | 名前の `ABCDEF+` のような接頭辞だけで埋め込み済みとは扱わない。通常のフォントと同じく実体を調べる |
| Helvetica などの標準 14 フォント | 埋め込みがなければ警告する。標準フォントだからといって除外しない |
| FontDescriptor またはフォントプログラム指定がない | 通常の Type1 / TrueType / CIDFont では非埋め込みとして警告する |
| 参照切れ、不正な型、空のストリーム、未対応の種類、元辞書を特定できない直接辞書・代替フォント | 非埋め込みとも埋め込み済みとも断定せず、検査未完了として警告する |

### 検査できない内容を明示する

`FONT_INSPECTION_INCOMPLETE` を新設し、解析失敗や判定不能を理由付きで報告する。失敗したページやフォントを「問題なし」とみなさず、可能な範囲の他ページの検査と画像比較を継続する。

PdfPig の通常の文字抽出は、PDF 注釈・入力フォームの外観に含まれる文字を取得しない。現行の PDFium 描画はこれらの外観も表示するため、該当する注釈やフォームがあるページには、検査範囲が本文・Form XObject に限られる旨を `FONT_INSPECTION_INCOMPLETE` で明示する。注釈を描画しなくする変更はしない。タイルパターンや Type3 字形内の別フォントなど、文字抽出だけでは使用を追跡できない構造を検出した場合も検査未完了とする。未使用リソースも含めて非埋め込みだと断定する代替案は採用しない。

この機能は「警告がないならすべての環境で同じ見た目になる」という保証にはしない。PDFium と PdfPig の解釈差、および破損 PDF に対する復旧処理は残る限界とする。

## 警告の出力と設定

- 既存の `warnings[].code` / `message` を使い、`schema_version` は 1 を維持する。メッセージに入力 A/B、1 始まりの元ページ番号、フォント名、取得できる場合はオブジェクト番号・世代番号、理由を記録する。新しいトップレベル JSON 項目は追加しない。
- 非埋め込み警告は入力・ページ・フォント辞書ごとに 1 件。同じフォントが複数ページにある場合は各ページで報告し、A と B は混ぜない。判定不能の直接辞書は取得したフォントの同一性で重複を防ぐ。ページ全体の解析失敗・検査範囲の制限は理由ごとにまとめる。
- メッセージは日本語。フォント名の HTML エスケープと長い名前の折り返しを確認する。JSON の文字列として正しく保存し、HTML やスクリプトとして解釈しない。
- 新しいしきい値や任意の上限・有効化設定は導入しない。既存のテキスト注釈件数上限は警告の検査対象を切り捨てる条件には使わない。将来、調整が必要なパラメータを追加する場合は承認済みのコメント付き YAML 方針に従う。
- 依存を追加せず PdfPig を利用する。ページ解析を注釈と共有し、同一ページの重複解析と全ページの保持を避ける。既存の描画用ストリームと PDFium の逐次処理は維持する。

## 代案

| 案 | 利点と制約 |
|---|---|
| 使用が確認できたフォントを判定し、不明・検査範囲外を警告（推奨） | 未使用フォントの非埋め込み警告を避け、判定できない内容も利用者に伝えられる。注釈・フォームの外観等では検査未完了が残る |
| リソース辞書にある全フォントを警告対象にする | 未使用の登録フォントにも警告が出る。外観のリソースも走査できるが、PDFium が動的に生成する外観まで同じ判定になるとは限らない |
| 不明・検査範囲外では警告を出さない | 表示量は少ないが、未確認を問題なしと誤解するおそれがあるため非推奨 |

## 検証と停止位置

1. 合成 PDF で Type1 / TrueType / Type0 と CIDFont / Type3、埋め込み有無、サブセット、標準フォント、混在、同名の別辞書・同じ辞書の別名・複数ページを確認する。外部の実帳票や OS のフォントファイルをテストデータとして追加しない。
2. 未使用フォント、Form XObject、直接辞書、参照切れ・不正な定義、解析失敗、注釈・入力フォームの検査範囲を確認する。フォントプログラムの有無を調べる辞書検証と、実際に文字抽出・描画できる PDF の結合検証を区別する。
3. 実 CLI で同一 PDF、差分あり、差分上限超過、片側ページ、ページ選択、画像/PDF 混在、`--no-html`、日本語・空白パスを確認。注釈省略時も警告を維持し、画像比較の結果と終了コードが変わらないことを確認する。
4. HTML の警告・理由・長い名前・特殊文字と 1280/390px の表示、キーボード、外部通信なしを確認。ページ解析の追加時間・メモリを記録する。
5. ビルド警告 0・全テスト・既存 37 ゴールデンを確認し、Windows publish と exe・配布 ZIP の静的検証を実施。Windows 実機確認は未確認として別記する。
6. SPEC・TASKS・検証記録を更新し、1 ローカルコミットで終了する。T2-6 と push は行わない。

## 承認前の試行

`out/t2-5-probe/` の独立したプログラムで、自作の合成 PDF 10 条件を既存の PdfPig 0.1.16 に渡した。製品への組み込みや T2-5 の受け入れ完了ではない。

| 条件 | 確認した結果 |
|---|---|
| 標準 Helvetica、Form XObject、不可視文字 | 各 3 文字から元のフォント辞書 `4 0 R` を取得 |
| 未使用の登録フォント | 文字要素 0 件 |
| 同名の異なるフォント辞書 | `4 0 R` と `8 0 R` を別々に取得 |
| 直接辞書 | 文字は取得できるが元辞書への参照は null |
| 注釈の外観にだけ文字がある | 本文の文字要素は 0 件。注釈の存在は辞書から確認可能 |
| 接頭辞付きだが実体がないフォント | 元辞書名と PdfPig の代替フォント名が異なる。元辞書を参照する必要がある |
| 自作 Type3 | CharProcs を持つ元辞書を取得 |
| 未対応フィルタで壊したテキスト | ページ解析が失敗。警告として扱う必要がある |

根拠：手元の PdfPig 0.1.16 の API ドキュメントに、`FontDetails.FontDictionaryReference` は同名のフォントを区別でき、直接辞書・代替フォントでは null と記載されている。[固定バージョンの Structure.cs](https://github.com/UglyToad/PdfPig/blob/a7bb35662bbbf405efddad50aedc9bcdcf515afc/src/UglyToad.PdfPig/Structure.cs) の `GetObject` で元の辞書を取得する。
