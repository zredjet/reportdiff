# T3-4a HTML からの除外 YAML の取り出し

対象は [TASKS の T3-4a](../TASKS.md)。T2-8 の検証済み安全網を保持し、未成立候補を保留して進める。比較コア・既存の出力値・画像・終了コードは維持する。

状態：2026-09-22、ユーザーが保留分を残して T3-4a へ進む方針を明示確認。実装・検証済み。[確認結果](../verification/t3-4a-exclusion-snippet.md)を参照。

## 振る舞い

- 各クラスタ行の「位置・大きさ」に折りたたみの「除外 YAML」を追加する。読み取り専用のテキスト欄に、`- {page: 2, x: 148.5, y: 7, w: 53, h: 7.5, note: ""}` のような一行を出す。
- ページは表示中の実ページ番号。`bbox_mm` を `report.snippet_margin_mm` だけ四方へ広げ、左上を 0.5mm 単位で切り下げ、右下を切り上げる。その後、正規化済みページの境界でクリップする。
- ページ寸法の mm 換算は、入力 A が PDF なら `dpi`、画像なら `image_dpi` を `Units` に渡す。CLI は A/B の実効 DPI が同じことを既に検証する。全体補正後も A／補正後 B の座標をそのまま用い、元 B へ戻さない。サイズ差は白埋め後のサイズを使う。
- 通常の座標は 0.5mm 刻み。ページ端で切った幅・高さのみ 0.5mm 刻みにならない場合がある。YAML の小数はカルチャ非依存、最大 10 桁とし、ページ端の mm→px の再変換でも端の画素を保持することをテストする。
- テキスト欄は JavaScript なしでも選択できる。JavaScript が使える場合は「YAML を選択」ボタンでフォーカスと全選択を補助する。クリップボード権限に依存しない。設定の `exclude:` の配列に貼るためのインデントを説明する。
- クラスタのないページに欄を出さない。欄を開くことや値を選ぶことでは比較結果は変わらない。

## 設定と互換性

`report.snippet_margin_mm` を追加する。既定 1.0mm、有限値 0〜20mm。切り出し画像の `crop_margin_mm`（既定 2.0mm）とは別に管理する。YAML の部分上書き・compare-dir の設定合成にも適用し、未知キーと範囲外はキー名付きのエラーにする。

JSON の `config.report.snippet_margin_mm` と HTML の実効設定を追加する。既存 JSON フィールドは変更せず、`schema_version=1` を維持する。注記は空文字列で固定し、PDF テキストや入力パスを YAML へ混ぜない。

## 検証

- 内外への丸め、余白 0 / 1 / 20mm、四辺・角・ページ全体、異なる DPI、カルチャ、設定の部分上書き、範囲外・非有限値。
- 実 CLI で HTML の欄を読み取り、その YAML を設定へ入れて再比較する。該当差分が消え、別ページの差分が残ること。画像・PDF・全体補正・ページ番号を確認する。
- 既定値／別余白で比較 JSON の既存値とすべての出力 PNG が一致する。追加する実効設定のみを比較対象から分離する。
- 42 ゴールデンを含む全回帰、ビルド警告 0。macOS Chrome の 1280 / 390px、キーボードによる展開・全選択、JavaScript 無効、外部通信なし、表示の確認。
- A4・300dpi 計測、Windows publish・バンドル・ZIP 静的検証。Windows 実行は未確認として残す。SPEC・設定例・設定リファレンス・利用案内を同期する。
