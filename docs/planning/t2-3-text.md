# T2-3 PDF テキスト層の注釈：仕様・実装計画

状態：2026-09-21、ユーザーの「OK、進めてください。」により推奨案を承認。開始点は `f6b03a2`（T2-2）。実装・検証済み。結果は [検証記録](../verification/t2-3-text.md)を参照。ローカルコミットまでで停止し、T2-4 には進まない。

## 推奨する動作

PDF の採用クラスタに、元の PDF テキスト層から得た単語を `text_a` / `text_b` として添える。文字列による差分検出・OCR は行わない。画像の判定、マスク、クラスタ数／矩形、分類、移動量、切り出し、終了コードを維持する。

- PdfPig の単語矩形とクラスタの矩形（表示用の余白なし）が正の面積で重なる単語を全文採用する。境界に接するだけなら含めない。単語の一部だけが変更されても、その単語全体を補足として示す。
- A/B それぞれの CropBox・MediaBox、元の描画サイズを使って左上原点の px に対応させる。正規化で追加した右・下の白い余白へ文字を伸ばさない。移動クラスタも各側の元座標で抽出する。
- 除外領域と正の面積で重なる単語は全体を省く。外枠など大きなクラスタでは、矩形内にある変更されていない文字も含む。同じ単語が複数のクラスタに重なれば、それぞれに記載する。
- 単語化は PdfPig の NearestNeighbourWordExtractor を用いる。上から下、同じ行は左から右の幾何的な順序で並べ、単語間は空白、行間は改行にする。同じ行は縦方向の重なりが小さい方の高さの半分以上あるものをまとめる。同一文字列・同一矩形の重複だけを除く。意味に基づく読み順、縦書きや複雑な段組みの復元は保証しない。
- PDF の抽出に成功し対象の単語がない場合は空文字列、画像入力や省略・失敗の場合は null とする。PDF と画像の混在では PDF 側だけに注釈を付ける。
- 比較して採用クラスタがあるページだけを抽出する。同一・too_different・片側だけのページでは既存どおりクラスタがないので注釈を実行しない。

## 省略・上限・警告

- SPEC の方針どおり、ページの回転が 0 度以外ならその側だけ注釈を省略する。対応を検証できないページ寸法・座標条件も省略する。`TEXT_ANNOTATION_SKIPPED` に A/B・ページ・理由を記録する。
- PdfPig のオープン・ページ抽出が失敗しても、PDFium による画像比較は続ける。`TEXT_EXTRACTION_FAILED` に A/B・ページと理由を記録し、失敗側を null とする。生の例外や抽出した本文を警告へ流さない。
- 1 ページ 100,000 文字要素または 20,000 単語を超えた場合は、その側の注釈を省略して警告する。解析そのものの実行時間・メモリの強制制限ではなく、抽出後の整形・対応付けを制限するもの。
- 1 クラスタ・片側の出力は 2,000 Unicode 文字まで。超過時は末尾を省略記号にし、`TEXT_ANNOTATION_TRUNCATED` に A/B・ページ・クラスタ番号を記録する。サロゲートペアの途中では切らない。
- これらの警告は既存の JSON / HTML の警告一覧に追加する。警告だけを理由に比較結果や終了コードは変えない。

## レポートと互換性

予約済みの `text_a` / `text_b` を使用し `schema_version: 1` を維持する。HTML の A/B 切り出しの下に「PDF テキスト」の補足を表示する。空文字列は「該当テキストなし」、省略・非 PDF は「テキスト注釈なし」と区別する。抽出文字列は HTML エスケープし、改行と長い単語を表示できるようにする。

PDF テキスト層には不可視の文字や不正確な文字情報が含まれることがあるため、注釈は画像を確認するための補助で、画像中の文字認識結果ではないと説明する。テキストの相違を検出数や kind に反映しない。設定項目や CLI オプションは追加しない。

## 依存の確認

NuGet の正式パッケージ **PdfPig 0.1.16** を固定する。2026-09-21 時点の安定版を [NuGet](https://www.nuget.org/packages/PdfPig/0.1.16) で確認。パッケージの nuspec は Apache-2.0、ソースコミットは `a7bb35662bbbf405efddad50aedc9bcdcf515afc`。net9.0 アセットを .NET 10 から利用でき、このターゲットに追加のパッケージ依存はない。製品への導入前に原文ライセンス・同梱通知・座標変換を確認する。

`ReportDiff.Pdf` に抽出・座標処理を置き、Core に PDF 依存を追加しない。入力ごとにストリームと PdfPig ドキュメントを所有し、必要なページを逐次処理して破棄する。既存の PDFium の逐次描画は維持する。

## 承認前の座標・依存の試行

製品コードを変更せず `out/t2-3-probe/` でパッケージの DLL と既存の PdfReader を使用した。採用版の [BasePageFactory](https://github.com/UglyToad/PdfPig/blob/a7bb35662bbbf405efddad50aedc9bcdcf515afc/src/UglyToad.PdfPig/Content/BasePageFactory.cs) と [OperationContextHelper](https://github.com/UglyToad/PdfPig/blob/a7bb35662bbbf405efddad50aedc9bcdcf515afc/src/UglyToad.PdfPig/Graphics/OperationContextHelper.cs) を確認し、CropBox は MediaBox と交差され、文字座標はその左下を原点とする位置へ変換済みであることを確認した。CropBox 原点をもう一度引いてはいけない。

合成 PDF の `Hello 123`（元の基線位置 50,220pt）を 300dpi で描画して確認した。各単語の対応矩形内に実際の黒い画素が存在し、ページの pt 寸法と描画 px 寸法は ±1px 以内で一致した。下表の抽出位置は最初の単語の左下。

| 条件 | 抽出位置（pt） | 描画サイズ（px） |
|---|---|---|
| 原点 0、240×300pt | (50, 220) | 999×1250 |
| CropBox [30,40,210,260] | (20, 180) | 750×916 |
| MediaBox にも非ゼロ原点 | (20, 180) | 750×916 |
| CropBox が MediaBox の外へ出る | (30, 190) | 791×958 |
| CropBox あり、ページ回転 90 度 | 回転値 90 を取得。注釈省略の対象 | 916×750 |

`UserUnit=2` も試行したが、PdfPig のソースは 1 以外の UserUnit を未実装と明記している。この例で描画と一致しても一般化せず、標準と異なる UserUnit は未対応の座標条件として省略・警告する。試行は API と座標変換の確認であり、フォント埋め込み・クラスタへの対応・製品の受け入れを済ませた結果ではない。

配布物には Apache-2.0 の LICENSE と NOTICES.txt に加え、内蔵 Adobe Glyph List / Zapf Dingbats Glyph List の BSD 形式の原文通知も保持する。nuspec とソースの確認だけで配布完了とはせず、製品導入後の publish・依存台帳・ZIP 検証まで行う。

## 代案

| 案 | 利点 | 注意点 |
|---|---|---|
| 重なった単語全文を補足表示（推奨） | 数値・語句を把握しやすく、既存の画像判定を維持できる | 変更されていない部分も含む。複雑な読み順は復元しない |
| 差分に触れた文字だけを表示 | 出力量を抑えられる | 文脈が途切れ、帳票の値を読み違えやすい |
| 抽出失敗を比較エラーにする | 注釈の欠落を見落としにくい | 画像として正常に比較できる PDF でも結果を得られなくなる |

## 受け入れ範囲と停止位置

- 座標の試行で、CropBox の非ゼロ原点・MediaBox との交差、各側の寸法、複数 DPI、回転の扱いを確認する。
- 合成 PDF に文字を埋め込み、変更、複数行、重なり境界、重複、除外、文字なし、特殊文字、混在入力、回転・抽出失敗・上限を検証する。既存 37 ゴールデンと全テストを維持する。
- 実 CLI の JSON / HTML / 終了コード、ブラウザの 1280/390px・キーボード・外部通信なしを確認し、PDF 注釈の時間・メモリを計測する。
- 原文ライセンス・通知と依存台帳を更新する。Windows publish・バンドル・ZIP の静的検証を実施し、Windows 実行は未確認として残す。
- T2-3 の検証・1 ローカルコミットまでで停止。T2-4、フォント非埋め込みの警告（T2-5）、push、Release 公開は行わない。
