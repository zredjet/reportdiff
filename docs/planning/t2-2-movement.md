# T2-2 移動判定の仕様・実装計画

状態：2026-09-21 にユーザーが「推奨案で実装を進める」を選択し、以下の仕様を承認。実装・検証済み。結果は [検証記録](../verification/t2-2-movement.md) を参照。ローカルコミットまでで停止し、T2-3 には進まない。push は別途指示があった場合に行う。

開始点：`1a416cd`（T2-1）。2026-09-21、macOS Apple Silicon。

## 承認された動作

検出済みの相違に「移動（推定）」を付ける。相違を消す機能にはせず、状態・生差分・クラスタの数／矩形／画素数・除外・ノイズ・吸収数・緑／赤の表示を維持する。

同じ内容が近くへ整数 px で平行移動したと確認できる場合だけ `kind: moved` にする。曖昧な一致、コピー、残った別の変更、色・形が変わったもの、検索範囲外は T2-1 の分類を残す。サブピクセルの移動量、回転・拡縮は今回扱わない。

### 設定

```yaml
move:
  search_mm: 5.0          # 上下左右それぞれの最大探索距離。0 は移動注釈を無効化
  min_score: 0.98         # 正規化相互相関の下限
  min_score_gap: 0.02     # 最良候補と別候補との差の下限
```

- `search_mm` は 0〜20mm、`min_score` は 0 より大きく 1 以下、`min_score_gap` は 0 より大きく 1 以下。NaN・無限・未知キーは既存設定と同じくエラー。
- 距離は `floor(Units.MmToPixels(search_mm, dpi))` px とする。指定した距離を超えず、各軸に適用する。300dpi・5mm は ±59px。斜めのユークリッド距離が 5mm に収まるという意味ではない。
- `normal` / `strict` / `loose` は従来どおり検出の位置ずれ・エッジ許容だけを上書きし、移動の設定は上書きしない。
- 実効値を JSON の config と HTML に記録する。これは検出アルゴリズムや既定の検出許容量の変更ではない。

### 判定

1. 採用クラスタの A 側の画像をテンプレートとし、B 側の周辺を `Cv2.MatchTemplate` / `CCoeffNormed` で探索する。テンプレートには上下左右 1mm の背景余白を付け、元座標で扱う。余白は `Units` で換算し、切り出し表示の余白とは独立する。
2. A 側にインクがなく平坦なテンプレート、必要な内容が画像端や切り出し端で欠けるもの、除外領域や採用しなかった成分の影響を分離できないものは推定しない。テンプレートの外接矩形内に別クラスタがある場合も、その差分を同じ対象として混ぜない。
3. 最大スコアが `min_score` 以上で、最良候補の周囲 3×3px（中心と隣接 1px）を除いた次点との差が `min_score_gap` 以上のときだけ候補にする。長い単純な線や反復パターンは候補が区別しにくく、推定されないことがある。最良候補が元位置の場合も moved にしない。
4. 元画像の色と形を再検証する。候補位置にずらして比較したとき、既存の一段目の差分が 0 であることを求める。比較の `max_shift_mm` による再探索で色・形の差を隠さない。色差や形状差は既存の比較許容量を基準とする。
5. 逆方向の探索でも移動先から移動元へ同じ対応が一意に戻ることを確認する。さらに元位置に残った B と移動量を戻した A も比較し、移動先の一致だけでは見えない残存物・追加を除く。
6. 関連する採用クラスタ全体の生差分がこの移動で説明できることを確認する。部分だけが動いた複合クラスタ、別の移動候補と競合するもの、片側が除外・ノイズ・上限で落ちたものは元の分類を維持する。移動判定のためにクラスタを結合・分割・削除しない。

1〜6 のいずれかを満たさないものはエラーにせず、T2-1 の分類と `shift_px: null` を残す。推定できないことによって既存の相違は消えない。画像の内容から推定するため、実際の編集操作としての「移動」と「削除して同じ内容を追加」は区別しない。

### 出力

- `shift_px` は `{ "dx": ..., "dy": ... }`。**A の位置から B の位置へ**のベクトルで、右が正、下が正。既存の位置ずれ吸収で B に適用する補正とは向きが逆になる場合がある。
- 移動元・移動先が別クラスタなら、両方に `kind: moved` と同じ A→B ベクトルを付ける。クラスタ数・番号・矩形は維持する。
- 各クラスタに `related_cluster_ids` を追加し、同じ移動に属する他のクラスタ番号を昇順で記録する。1 クラスタ内で完結する場合と moved でない場合は `[]`。自分の番号は含めない。
- 既存フィールドの型を変えない追加項目として `schema_version: 1` を維持する。読み手は未認識の項目を無視できることが前提。旧出力には関連 ID がない。
- HTML は「移動（推定）」と「右／左 X px、下／上 Y px」、関連クラスタへのリンクを表示する。0 の軸は省略する。凡例に推定であること・A→B の向きを説明する。
- ページの重ね描き・切り出し色は T2-1 と同じ。移動箇所も相違のままなので終了コード・要約のクラスタ数を変えない。

例：クラスタ 1 から 2 へ右 59px 動いた場合、両方の `shift_px` は `{ "dx": 59, "dy": 0 }`、関連 ID は 1 側が `[2]`、2 側が `[1]`。A/B を逆に比較すると dx は −59 になる。

## 比較した代案

| 案 | 利点 | 注意点 |
|---|---|---|
| 高い相関・一意性・色と形・双方向確認を要求（推奨） | 誤った移動ラベルを抑え、内容の変更を残せる | 単純な長い線、反復、複合クラスタの一部の移動は推定されない |
| 最も高い相関があれば移動とする | 多くの移動候補にラベルが付く | コピー、繰り返し、移動＋別の変更を誤って単一の移動としやすい |
| 移動元クラスタだけに注釈を付ける | JSON の項目追加を避けやすい | 移動先が「追加」のまま残り、関連が明確でない |

## 試行による確認

製品コードを変えず、`out/t2-2-movement-probe/` に既存 Core を参照する試行プログラムを作成した。300dpi、白地に非対称な黒図形、±59px の検索、周辺 1px を除いた次点スコアを使用。手動で決めたテンプレート範囲での初期確認であり、クラスタからの自動切り出し・関連付けや実装の受け入れではない。

| ケース | 最良候補 | 最良スコア | 次点との差 | 候補をそろえた比較の差分（正／逆） |
|---|---|---:|---:|---:|
| 右・左・上・下に 24px | 指定した移動量 | 約 1.000 | 約 0.233 | 0 / 0 |
| 右 24・上 24px | (24, −24) | 約 1.000 | 約 0.233 | 0 / 0 |
| 検索端の右 59px | (59, 0) | 約 1.000 | 約 0.233 | 0 / 0 |
| 範囲外の右 60px | (59, 0) | 0.869 | 0.204 | 132 / 0 |
| 元を残してコピー | (24, 0) | 0.866 | 0.098 | 93 / 317 |
| 同じ候補が左右 2 か所 | (−24, 0) | 約 1.000 | 0 | 0 / 162 |
| 移動＋色変更 | (24, 0) | 0.937 | 0.219 | 235 / 132 |
| 移動＋濃淡変更 | (24, 0) | 約 1.000 | 約 0.233 | 140 / 100 |
| 移動＋形状変更 | (24, 0) | 0.917 | 0.182 | 54 / 0 |
| 移動元に別の小さい図形が残る | (24, 0) | 約 1.000 | 約 0.233 | 0 / 37 |
| 長さ 200px の単純な線 | (24, 0) | 約 1.000 | 0.012 | 0 / 0 |

移動先が完全一致しても、移動元に別の差分が残るケースはあるため、相関だけで moved にしない。長い単純な線は次点との差 0.02 を満たさず保留する。この保守的な挙動を推奨する。

## 実装・受け入れの範囲

- Core の移動注釈処理、設定の読み込み・検証・実効値、JSON / HTML、README / SPEC / TASKS を同期する。新規依存は不要。
- 既存 37 ゴールデンの検出と統計、最適化前後、移動注釈あり／なしの生差分・輪郭・削除マスク・クラスタ数・矩形・画素数の一致を維持する。
- 上下左右・斜め、A/B 反転、検索境界と範囲外、同一／複数クラスタ、画像端、通常／厳密設定、300/400dpi、非連続 Mat、除外・ノイズ・上限、入れ子を検証する。
- 無地、反復、コピー、移動なし、色変更、形状変更、移動＋残存差分、異なる候補の競合では移動と断定しないことを検証する。
- 合成 PDF を実 CLI プロセスで比較し、JSON の符号・関連 ID、HTML のラベル・方向・リンク・エスケープ、終了コードを確認する。
- macOS Chrome で 1280/390px、キーボード、外部通信なしを確認。A4 の時間・メモリと多数候補の負荷を計測する。
- ビルドと全テストを通して 1 ローカルコミット。Windows 固有の実行・表示は未確認として残す。T2-3・push は行わない。
