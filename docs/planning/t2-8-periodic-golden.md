## 範囲と進め方

1. 既存のビルド・テストと、保存済み PNG による Python 参照照合を実行する。日本語の既存 PNG はローカルフォントで再生成しない。
2. 追加候補の描画条件を固定して、製品コードと正本のゴールデンを変更せずに予備検証する。再現スクリプトと観測値は検証記録から参照できるよう残す。
3. 成立した独立ケースを単位として、Scene の生成・C# の生成一致テスト・追加期待値・SPEC 9 章を更新する。未成立・未承認の候補は正本へ入れず、T2-8 全体の未完了項目として残す。既存 expected.json の各ケースと PNG のハッシュは維持する。
4. 追加した全ケースの参照／C# 一致、既存回帰、A4 計測、Windows publish / ZIP の静的確認を終えてから完了とする。

T2-8 には個別の「着手前に確認する判断」はなく、承認済みタスクと着手指示の範囲で予備検証を進める。新しい仕様判断は行わない。

## 追加候補

| ID | 条件 | 期待 |
| --- | --- | --- |
| I06 | 1px 幅・周期 4px の点線、全体 1px ずれ | 相違なし |
| I07 | 同点線の 2px ずれ、±2px の別解 | 相違なし |
| I08 | 周期 4px の網点、2px ずれ | 相違なし |
| I09 | loose、周期 8px の点線、4px ずれ | 相違なし |
| D16 | 点線の点が 1 つ欠ける | 1 クラスタ |
| D17 | 両端を固定し、点線の周期を 4px から 5px へ変更 | 1 クラスタ以上 |
| D18 | 1px 幅の一重線から、中心間 2px の二重線へ変更 | 1 クラスタ |
| D19 | loose、2px 幅の一重線から、中心間 4px の二重線へ変更 | 1 クラスタ |
| J07 / J08 | 9pt・300dpi のハ→八、ニ→二。J 系と同じ生成条件 | 各 1 クラスタ |

描画位置・点の長さ・線端の扱いと、周期パターンが一段目／二段目のどちらを通るかを予備検証で記録する。条件を満たすためのしきい値変更や、失敗後に図形を変えて合格させる調整は行わない。日本語は使用フォントを記録し、既存 J 系とのフォント条件の一致を確認できるまで採用しない。

## 再開範囲：二段目を実際に通る独立ケース

ユーザーが「二段目を実際に検証できる周期ケースを別途設計する方針」を承認したため、以下を別 ID として設計・登録する。D16 / D17 の検出期待は変更せず、L 系への移行は今回の承認に含めない。元の候補を加工して合格したことにも扱わない。

| ID | 条件 | 受け入れ条件 |
| --- | --- | --- |
| I10 | 周期 4px、幅 2px・長さ 16px の縞。端の 128px は白へ線形に薄くする。B を横 +2px | 一段目の候補 > 0、±2px とも残差 0、1 group 吸収、相違なし |
| I11 | I10 の縦方向版。B を縦 +2px | 同上。縦 ±2px の残差を確認 |
| I12 | loose、周期 8px、幅 4px・長さ 16px の縞。端の 256px は白へ薄くする。B を横 +4px | 一段目の候補 > 0、±4px とも残差 0、1 group 吸収、相違なし |
| D20 / D21 | I10 / I12 の B から中央の縞を 1 本除く | すべての探索ずれで残差が残り、1 クラスタとして検出 |

端の濃淡は入力画像の仕様であり、比較器のしきい値ではない。画像端の複製・除外領域・画像の切り出しを利用して不都合な画素を隠さない。すべて画像内に白余白を持つ有限長の模様とし、ゼロ残差の確認は group の初期候補画素だけでなくページ全体を対象にする。

Python ではページ全体の特徴量をずらして全候補の残差数を保存する。C# では別途生成した入力を PNG と完全照合し、一段目の候補が存在すること、符号の異なるずれが両方ゼロ残差であること、製品比較器が吸収することを検証する。D20 / D21 は同じ仕組みでも実際の欠落を吸収しない対照ケースとする。製品の比較式・既定値は変更しない。

## 停止条件

追加候補が期待に合わない場合は、その候補の登録を比較式・しきい値・期待値を変更せず停止する。原因を一段目の許容、二段目の吸収、クラスタ化に分けて調べ、参照と C# の結果を報告する。D16 / D17 を承認なしで L 系へ移行しない。未承認の結果を正本 expected.json に登録せず、T2-8 全体を完了にしない。2026-09-22 以降は保留範囲を維持したまま、依存のない T3-4a を進める。
