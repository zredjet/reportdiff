# T3-1c：文字候補と構造帯の独立検証

2026-09-22。続行指示に基づき、[全画素一致を要する境界案](t3-1c-context-verification.md)の次に、自動候補と帯の帰属を検証する。製品の採否・出力にはまだ接続しない。

## 試行する範囲

最初は同一寸法・同一DPI、全体補正なし、本文の行間隔が一定で、両端の固定部分の根拠を複数ページから取れる入力に絞る。これは任意の可変行高の帳票への対応を意味しない。設定を弱めず、不足・矛盾・曖昧性は見送りとして記録する。

- `PdfTextReader`と既存`TextLineLayout`で元PDFの語・行を取得する。数字・全角半角・大小文字を同一化しない。
- 同じ物理ページが少なくとも2ページ存在するA/Bから、位置と文字が共通する先頭・末尾の行を固定部分の候補にする。ページ途中の反復行は固定部分へ取り込まず、先頭／末尾の連続部分だけを使う。各側2行以上を必要とし、対応する固定部分の画素も全ページで一致することを確かめる。本文自体が全ページの先頭／末尾で反復する場合の意味の曖昧さまでは解消しない。
- 固定部分の間の全非白画素（どれかのBGR値が255未満）から本文の上下端を求める。文字の外接矩形だけで罫線・薄色を落とさない。本文行の間隔、上下端と行数の関係を検査する。
- ページ内で一意に対応する複数行の変位から送りの高さを求める。複数の変位候補が支持される場合は一つを選ばない。送り元の本文末尾と、隣接物理ページの送り先本文先頭をその高さで取る。本文領域の範囲指定や生成時の正解座標は入力にしない。
- 帯内の全文字が同順で一致し、本文中に同名行が重複せず、単語を切らないことを必要とする。全幅・全画素一致と両端の元ページ置換検証を通った帯だけを画像検証済み候補とする。異なる切断を試して差分0の場所を探す処理はしない。
- A→B／B→Aを同じ処理で調べる。pとp+2は隣接扱いせず、渡されていないページを読み足さない。抽出・資源・固定部分の根拠が不足する場合は見送る。

## 構造帯との対応

本文の一意なページ内対応から表示写像を作る。本文端の未対応帯をCから省略できるのは、同じ側・物理ページ・開始位置・高さが検証済み送り候補と完全一致する場合に限る。本文途中の挿入／削除は前後の独立した対応行の支持を要する。

元の全行を一度ずつ覆い、純白余白を保持し、既存`RowComparisonSurface.Create`の安全条件を通す。候補の生差分を減らすために境界を動かさない。帯の一致に失敗した場合、その端点のページは元の比較を維持する。ここでの写像・候補は独立ツールの出力で、製品の`structural_change_id`や集約件数はまだ作らない。

帯の画像が一致しても、一方のページの構造写像を作れなければ、そのリンクの範囲対応は未成立とする。`band_verified`は画像条件だけ、`range_correspondence`は両端の範囲対応、`all_paired_maps_built`は文書内の対応ページすべての写像という別の証拠を保存する。部分的な比較面の成功を文書全体の採用へ昇格しない。

片側だけのページは既存の未比較状態のまま、検証済み候補帯・複数ページで画素を確認した固定部分・未確認の非白内容の範囲を区別する。帯外に薄い塗りが残る場合、ページ全体を確認済みにはしない。

## 照合する証拠

前回の20PDFのハッシュを固定する。正解帯座標は推定処理へ渡さず、実行後に外側の検証器で照合する。R10／R11／3ページ連鎖、A/B交換、文字変更、画素だけの変更、境界内外の変更、反復行、固定部分不足を含める。推定した帯とCから外した帯の範囲、元画素の被覆、残る差分、未比較の網羅性を分けて記録する。

固定された位置・行間隔への依存を検査する入力も追加する。一般のSkia入力、可変行高、領域・除外・全体補正、因果集約、候補上限の製品値、性能、HTML／CLIへの接続はこの独立検証だけでは受け入れない。

## 今回の結果

32PDF・36実行・480参照比較で、この限定範囲の候補・元画素被覆を検証した。本文位置350/400px・行間隔125/150pxも推定できるが、125px間隔の一部末尾で描画が1px長くなる場合は比較面を見送り、元の差分を維持する。[検証結果](../verification/t3-1c-candidate-inference.md)を参照。自動送りや因果集約を製品へ接続する前に、別系統のPDFと構造写像の部分失敗時の一括見送りを検証する。
