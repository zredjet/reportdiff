# T3-1c A4の元描画と比較面の切り分け

2026-09-23。[前工程](../verification/t3-1c-scale-measurement.md)の次の作業として承認された診断範囲。採用期待が未成立だった入力を変更せず、PDFの配置命令、製品と同じ描画、C/Dの転写を分けて調べる。

## 固定するもの

- 前工程のSkia 24行／48行、描画端を内側へしたSkia、分数pt／整数ptのType3、成立対照の疎なType3。各2ページの新旧12PDFをSHA256で固定する。
- 製品のPDF読み取り・比較式・しきい値・送り帯の全画素一致・文書単位の採否・raw evidence・検出期待を維持する。
- 診断用の描画対照や採用されなかった候補C/Dは、利用者向けレポートや送りの根拠へ流用しない。PDFの再生成・書き換えはしない。

## 診断方法

1. pypdfで元の描画命令を読む。本文の文字列で新旧を対応付け、配置だけを取り除いた命令列と描画フォントを照合する。製品の候補ID・採否に依存させない。
2. 製品の元PNGとPDFtoImage直接APIの結果を全画素比較し、前工程のPNGともハッシュを照合する。寸法を明示する切り上げ／切り捨て、およびパスのアンチエイリアス無効の対照を逐次描画する。
3. 各対応行とページをまたぐ送り帯を、元画素のまま比較する。対応行で差があっても文字の一致で同一画素と認定しない。
4. 範囲が成立した整数pt／疎な対照について、実際のC/Dを出力する。NumPyで元PNGからCを再構成し、Cの判定マスクをDへ写して照合する。判定画素と非連続の継ぎ目の距離も記録する。
5. Cの判定マスクは既存Python参照実装と照合する。診断結果、元入力・製品ソース・ツール・証拠のハッシュを保存する。

## 判断の境界

転写ミスが確認できた場合は、元画素の被覆と参照結果を保つ修正を検討する。描画時点に差があり比較式どおりに検出される場合は、その差を消す修正を行わず対応範囲の制約として記録する。単一の対照だけ改善する描画変更を製品へ採用しない。

この診断の完了はA4送り採用の受け入れではない。前工程の未成立9条件、Windows・実帳票、全体補正との座標合成、複数原因・数値変更、時間・RSSの残件を維持する。ブラウザーの保留は再開しない。[結果](../verification/t3-1c-raster-diagnosis.md)を参照。
