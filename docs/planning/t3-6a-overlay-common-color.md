# T3-6a 確認用オーバーレイの共通色

2026-09-22、ユーザー承認済みのタスクを具体化する。既定は候補の薄いグレー `#CCCCCC` を採用し、実サンプルで表示を確認する。判定コアは変更しない。

## 設定と表示式

`report.raw_overlay_common_color: "#CCCCCC"` を追加する。RGB 各 8bit の 6 桁十六進数だけを受け付け、英字の大小は許容して大文字で記録する。YAML の # はコメント開始なので引用符を必須として説明する。共通 YAML → 帳票別 YAML で上書き・省略時の継承を行い、profile / dpi / --raw-overlay は色を変えない。無効時にも設定値を検証・記録する。

グレー変換は従来の整数式を保つ。共通成分の濃さを `c = 255 - max(gA, gB)` とする。設定色の各チャンネルを `CR, CG, CB` として次の RGB を保存する。

```text
R = gB          + floor((c * CR + 127) / 255)
G = min(gA,gB)  + floor((c * CG + 127) / 255)
B = gA          + floor((c * CB + 127) / 255)
```

白背景は白、片側だけの成分は従来の赤／青、両側が黒なら設定色となる。共通の濃淡は白と設定色の間に連続して残す。黒指定は従来式と全画素で一致する。比較マスク・吸収・除外・分類を参照せず、入力・色が同じなら判定設定によらず同じ画像になる。等輝度の色相差が見えない限界は維持する。

表示方式は `grayscale_red_blue_common_color_v2` とする。個別 JSON の config.report に実効色を、各 raw_evidence に common_color を記録する。schema_version は 1 のまま。旧結果の raw_evidence に common_color がなければ従来の黒として扱い、過去の方式名の意味は変えない。

HTML は共通色の見本と色コードを凡例に併記し、色コードの文字は通常の読みやすい文字色を使う。任意の色でも凡例が白地へ消えないようにする。PNG 単体・no-html・一括比較も同じ色を使う。設定リファレンス・全項目例・SPEC・README・同梱サンプルを更新する。

検証は従来の黒指定の全グレー値対、既定／任意色の固定画素、濃淡・片側・白・交換・非連続画像、設定型・不正値・継承、CLI／PDF／画像／一括／no-html、旧結果の読み込み、判定と既存画像の不変性、ブラウザと A4 計測を対象にする。
