# T3-7 ページ進捗表示

2026-09-22、ユーザー承認済みのタスクを具体化。表示は Cli 層の ConsoleProgress に集約し、比較コア・レポート内容は変えない。追加依存なし。

- ページ選択後の対象数と現在着手する順番を `処理中 3 / 20 ページ` と表示する。選択指定時は元ページ番号も添える。ページ読み込み前に書き込み、Flush してから処理する。
- 実際の標準出力がリダイレクトされず、TERM が dumb でなく、端末幅を取得できて表示が収まる場合に限り、復帰文字と末尾空白で同一行を更新する。任意のファイル名は別行で制御文字を除去して出す。
- リダイレクト・幅不足・端末幅取得不可では通常の行を出す。更新中に幅が不足した場合も進捗行を閉じて通常行に戻す。テスト等で差し替えた TextWriter は既定で通常行とする。
- ページ処理後はレポート出力中と表示する。最終ページの開始は完了を意味しない。例外経路は IDisposable と個別エラー処理で進捗行を閉じ、次のファイル・エラー・従来の完了要約と混在させない。
- compare-dir の総数はファイル対ごとの選択ページ数。片側だけのファイルは開かない。全体の一覧保存時は一覧レポート出力中と表示する。quiet はすべての通常表示を抑止し、エラーは維持する。

検証は端末幅を差し替えた表示テスト、実 CLI のリダイレクト、複数ページ・片側ページ・途中エラー・一括比較、PTY の実出力、全既存テストで行う。Windows のユーザー端末での見え方は実機確認として分ける。
