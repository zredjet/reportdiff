# 行整列の内容比較面の固定入力

174 条件（PDF 描画由来 78、固定フッター 24、挿入・削除混在 12、複数挿入 12、境界をまたぐクラスタ 6、既存ゴールデン 42）。自作の合成入力だけを使用する。

`docs/verification/t3-1b-common-surface.md` の独立試行で、純白余白を残す案が各方向の基準入力・生差分マスクを復元した条件を固定した。`cases.json` の期待統計とマスクの SHA-256 は当時の Python 参照実装による結果。マスクのハッシュは復号した 8bit 全画素を行順に連結した値であり、PNG の圧縮形式には依存しない。入力 PNG のファイル名はファイル全体の SHA-256。同一画像は共有し、既存 42 件の画像は `golden/` を参照する。

`roles` は試行で与えた正解の写像の意味であり、製品が画像から推論したものではない。この安全網は写像・近傍・比較・転写を検証する。行推定や R01〜R09 の受け入れを代替しない。

入力と期待値を現行製品の出力で再生成しない。変更が必要になった場合は、元の試行、独立した参照結果、検出を保持する理由を確認する。v0.1.4 のオーバーレイ色設定はこの比較面の期待値に含めない。
